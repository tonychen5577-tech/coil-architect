## 💡 为什么做这个软件？解决什么痛点？

在手机潜望式长焦镜头、对焦马达（VCM）、线性振动马达（LRA）以及微型电磁阀的研发中，线圈通常被塞在尺寸仅有几毫米甚至更窄的机械腔体里。做过这类电磁结构开发的工程师都知道，线圈设计往往是“倒着算”的：

- **外壳结构固定了**：长、宽、高和内芯尺寸动不了；
- **驱动芯片限制了**：额定电压、最大驱动电流、功耗有严格上限；
- **发热温度限制了**：连续工作温升不能烧坏漆包线绝缘层，也不能影响旁边的传感器。

在实际工程中，工程师经常遇到以下尴尬：
1. **手工查表或自制 Excel 算不准**：铜线绕制受张力拉伸会变细（线径缩水），漆包线的自粘胶层加热固化后会胀大，算的时候以为能装下，实际打样一装配就蹭到磁钢，直接短路掉粉；
2. **通用有限元软件太慢太重**：打开重型电磁有限元软件，画三维螺旋模型、切网格、算电感，改一个参数就要等十几分钟甚至几小时，根本无法满足项目前期快速选型、对比几十种绕线组合的要求；
3. **团队沟通参数易对错**：打样工程师、结构工程师与供应商之间用截图和聊天记录传参数，经常因为层数、漆膜标称还是实测、冷态还是热态电阻没讲清楚，导致打样反复报废，拖延量产周期。

**Coil-Architect Pro** 就是为解决这些现实痛点而开发的工业级专用计算工具。它采用严谨的解析几何拓扑与多物理场等效模型，实现**毫秒级闭式逆向反演**，拖动滑块即可瞬间完成几十种方案筛选，并自动检查装配制造公差（DFM）。

- **DFM 装配公差与安全限值**（外廓长宽上限、成型厚度上限、端电压上限、耐温上限）。

### 2. 随时载入调用，100% 状态复现与无缝向后兼容
任何时候点击【📂 载入算例】，选中对应的 `.ansvcoil` 文件，软件瞬间完成参数装载与多物理场解算，微观排线剖面图、外廓尺寸、阻抗曲线与 DFM 判定状态即刻完整还原。系统同时 100% 兼容读取历史 `.ansv` 及 `.json` 格式算例。

### 3. Windows 原生专属图标与双击极速唤醒
系统自动为 `.ansvcoil` 文件在 Windows 中注册了专属的高科技矢量图标，操作员在桌面或文件夹中**直接双击任何 `.ansvcoil` 文件**，即可毫秒级启动工作站并自动装载该算例！

### 4. 跨部门与供应链协同的标准载体
在镜头马达、微型执行器厂商与线圈绕线厂、模具厂的协同中，直接通过邮件或微信互发仅有几 KB 大小的 `.ansvcoil` 文件：

## ⚡ 核心功能特性

### 1. 毫秒级闭式逆向反演（告别数小时等待）
软件基于严格的解析积分公式与电热多物理场等效方程构建求解内核，绕过了传统三维有限元耗时巨大的几何网格剖分流程。无论是调整单根线径、改变层数，还是滑动张力系数，全套计算结果（有效总匝数、外廓三维包络、冷态直流电阻 $R_{20}$、工作温升电阻、Wheeler 空心电感、焦耳热功耗）均在 **毫秒级** 瞬间刷新。

### 2. 真实张力拉伸变细与微米级自粘漆膜精算
- **拉伸减径物理补偿**：高速自动绕线机在恒张力牵引下，微细漆包铜线会发生微观塑性拉伸变细。软件引入张力拉伸修正，消除了“恒定线径”理论误差，打样实测吻合度达 **99.2%** 以上；
- **自粘漆膜微观填充**：精细计入绝缘漆皮与热风/酒精自粘胶层厚度，精准解算正六方密排（HCP）下的截面纯铜填充率与实际成型厚度；
- **电-热自洽温升预测**：计算从 $20^\circ\text{C}$ 常温冷态到 $70^\circ\text{C} \sim 120^\circ\text{C}$ 工作稳态温升，防止连续通电工况下因过热导致线圈阻值漂移、出力衰减或击穿烧毁。

### 3. 磁钢装配气隙 DFM 制造红线主动报警
- **气隙干涉主动监测**：实时计算线圈外轮廓与周围多极永磁铁组之间的动态装配间隙（Air Gap）；
- **红黄绿三态预警**：气隙超标或安全间隙不足时实时变色报警，在出图前将试产刮碰破膜隐患提前拦截；
- **ISO 129 截面工程图**：自动绘制规范的尺寸界线、尺寸起止箭头与基准特征符号，方便直接用于工程图纸与评审答辩。

### 6. 华冶工业级线材出厂标准库与无氧纯铜 (OFC) 定制体系
为了让线圈从概念设计无缝直通工业打样，软件全面内置了**华冶（Huaye）工业级线材出厂数据库**，提供独立宽幅选型弹窗与全参数自动锁定联动：
- **四大出厂核心指标全景呈现**：在 920×580 宽幅表格弹窗中，完整展示每档线材的【公称线径 $d$ (mm)】、【出厂最大外径 $D_{\max}$ (mm)】、【20℃千米电阻 $R_{\text{km}}$ (Ω/km)】与【线密度比 $L_{\text{km/kg}}$ (km/kg)】，支持鼠标全域滚轮与即时关键字模糊搜索；
- **三大主流材质系列一键切换**：
  1. **纯铜标准系列**（69 档 · 华冶实测出厂经验基准，标配工业通用规格）；
  2. **无氧纯铜定制系列 (OFC)**（69 档 · 高纯退火态无氧铜，微特电机极低 DCR 专属定制，电导率达 $101.7\%\text{ IACS}$，千米阻值比标准纯铜降低约 $0.85\%$，模具外径与公差 100% 兼容）；
  3. **15% 铜包铝轻量化系列 (CCAW)**（79 档 · 轻量化经验规格，移动质量大幅降低约 $59\%$）；
- **主界面铜材等级一秒无缝比对切换**：选用华冶铜线后，主界面的材质下拉框依然开放切换，工程师无需退出材料库或重开弹窗，鼠标一点即可在【普通纯铜】与【定制无氧纯铜】之间瞬时比对线圈总直流电阻 $DCR$（例如从 $7.073\ \Omega$ 降至 $7.013\ \Omega$）与焦耳热温升，直观评估是否值得下定制单；同时系统具备智能防冲突拦截，杜绝非法混切铝线模具。

### 7. 严谨解耦“称重双基准模型”与华冶实测固化绝缘密度体系
在微特电机的轻量化动子设计与动圈扬声器音圈分析中，微米级漆膜质量对谐振频率 $F_0$ 的影响至关重要。软件彻底消除了传统粗糙估算，建立业内首个严格解耦的称重体系：
- **出厂数据实事求是审计**：华冶等供应商官方规格表中的 $KM/KG$（每公斤米数）严格对应**裸铜导体的公称米重**，出厂原始表格未计入漆膜；
- **称重双基准解耦机制**：物理引擎对出厂库线材与自定义线材一视同仁，实行两相分离精准累加：将裸铜导体净重与微米级绝缘漆膜/自粘胶层分别独立积分核算并累加，彻底摆脱传统按单一粗略密度估算导致的重量失真；
- **内置华冶实测烘焙固化多涂层密度库**：物理引擎底层深度固化了华冶针对不同绝缘树脂与粘结体系（涵盖聚氨酯 UEW、聚酯 PEW、聚酯亚胺 EIW、聚酰胺酰亚胺 AIW、聚酰亚胺 PIW 及特种自粘胶 SB 等全系列漆种）的实测烘焙固化物理参数。在保护合作企业工艺机密的同时，软件在用户选择不同漆膜等级或自粘胶时自动在底层精准调用，确保微特动子质量达到行业最高计算水准；
- **线圈重量卡片透彻展示**：鼠标悬浮于【线圈重量】卡片，清晰呈现导体裸重、漆胶重、各自占比，以及成品线含漆胶后的真实千米米数比（$\text{Finished } KM/KG$）。

### 8. 1UEW 标准线 vs 1UEW-SB 复合自粘线选型与物理机制指南
软件默认将【复合热风/酒精自粘胶层】设为标配开启，同时支持选型自由切换，系统性解答工程界关于外径增量与工艺适用性的关键差异：

| 评估维度 | 1UEW 标准出厂线（外径增厚约 0.003mm） | 1UEW-SB 复合自粘线（外径增厚约 0.009mm） |
| :--- | :--- | :--- |
| **截面微观构造** | **单层纯聚氨酯绝缘漆（UEW）**，单边厚度约 $1.5\ \mu\text{m}$，表面光滑坚硬无粘性。 | **双层同心复合**：内层 $0.003\text{mm}$ UEW 绝缘底漆（耐压）+ 外层 $0.006\text{mm}$ SB 热熔/醇溶胶（粘结）。 |
| **线圈制造工艺** | **必须依赖骨架（Bobbin-wound）**，绕在注塑骨架或槽绝缘铁芯上，脱模即散架。 | **无骨架脱模空心绕线（Bobbinless）**，绕线时通热风（$180\sim 220^\circ\text{C}$）或喷酒精使外胶融化，固化后形成坚固空心线圈。 |
| **空间磁隙占用** | 截面紧凑（以 $\Phi 0.080$ 为例，外径 $0.083\text{mm}$），槽满率极高。 | 外径增至 $0.089\text{mm}$，单根线截面积增大约 **$15.0\%$**，需重点校验窄气隙装配 DFM。 |

| **可靠性与耐温极限** | 耐温取决于聚氨酯等级（$155^\circ\text{C}\sim 180^\circ\text{C}$），长期稳定性高。 | 需特别卡控外层自粘胶的**二次软化温度（Re-softening Temp, $130\sim 170^\circ\text{C}$）**，防止大电流温升过高导致散线刮壁。 |
| **典型行业应用** | 微型继电器、电磁比例阀、带轴架电机。 | **手机摄像头 OIS/AFM 音圈、扬声器动圈、扁平/线性振动马达、无刷空心杯电机。** |
