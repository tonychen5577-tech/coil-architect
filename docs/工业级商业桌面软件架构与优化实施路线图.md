## 第一步：交互体验与工业可靠性防损优化 (UX & Reliability)

### 1. 全局滚轮防误触过滤器 (`GlobalNoWheelChangeFilter`)
* **痛点**：操作员在滚动左侧长页面浏览参数时，指针掠过 `QSpinBox`、`QDoubleSpinBox`、`QComboBox` 会无意篡改关键几何或工艺参数（如线径、匝数）。
* **实施方案**：
  * 在 Qt 顶层安装全局事件过滤器；
  * 拦截数值控件与下拉控件的 `Wheel` 滚轮事件；
  * 将滚轮事件沿着组件树冒泡传递给外层的 `QScrollArea`，实现平滑滚动且绝对不触发调值。

### 2. 突发断电防损：算例与配置“原子写 (`Atomic Write`)”
* **痛点**：车间产线总闸突发断电时，若正在保存算例，传统 `open("w")` 会因磁盘缓冲区未物理落盘导致文件损坏或变成 0 字节。
* **实施方案**：
  * 封装 `atomic_write_json` 与 `atomic_write_text` 通用模块；
  * 先写入同分区临时文件 `.tmp_{pid}`；
  * 执行 `flush()` 并在操作系统层调用 `os.fsync(fileno)` 强制刷入硬件物理扇区；
  * 最终使用 `replace` 原生原子重命名覆盖目标文件，确保断电时“要么是旧版本完整，要么是新版本完整”，杜绝 0 字节空洞。

### 3. 右下角状态栏三行版权常驻 + 16:9 标准“关于系统”对话框
* **痛点**：缺乏规范的商业品牌标识、版本构建追踪及算法版权直达入口。
* **实施方案**：
  * 主界面状态栏右下角通过 `addPermanentWidget` 常驻规范的三行版权：
    1. `Core Architecture & Algorithm: Yaming.Chen (ansv.net)` (支持浏览器直达外链)
    2. `Version 1.0.0 | Build 20261014`
    3. `Copyright © 2026 ansv.net & Yaming.Chen. All rights reserved.`
  * 新增 16:9 工业宽屏标准的“关于 Coil-Architect Pro”弹窗，提供机器码一键复制、官网直达按钮与软件技术指标说明。

### 4. Windows 任务栏图标 Win32 原生注入
* **痛点**：Python PyQt 打包后，在 Windows 10/11 任务栏和 Alt+Tab 切换窗口时，常被系统识别为默认的黑色控制台图标或白板图标。
* **实施方案**：
  * 在程序入口调用 `ctypes.windll.shell32.SetCurrentProcessExplicitAppUserModelID("ansv.net.coilarchitect.1.0")`；
  * 向主窗口句柄 `HWND` 发送 `WM_SETICON` Win32 消息，强制绑定大图标 (32x32) 与小图标 (16x16)。

### 5. 高低分辨率与 DPI 自适应 (`adapt_dialog_geometry`)
* **痛点**：工控机小屏 (1366x768) 或开启 150%/200% 缩放下，弹窗高度超标导致底部的“确定/保存”按钮被 Windows 任务栏遮挡。
* **实施方案**：
  * 封装通用居中与防爆工具函数，动态检测剔除任务栏后的 `availableGeometry()`；
  * 严格限制弹窗最大尺寸不超过工作区的 88%，确保在任何分辨率与缩放下按钮永不被遮挡。

## 第二步：商业授权、反作弊与防编译安全加固 (Security & Licensing)

### 1. 0ms 启动硬件指纹提取加速
* **痛点**：每次启动若调用 wmic 或 PowerShell 提取主板 UUID 会造成 2~3 秒的冷启动假死卡顿。
* **实施方案**：
  * 优先使用 Python 内置 `winreg` 模块瞬时（< 1ms）提取 `HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid`；
  * 与本地持久化指纹缓存比对，一致则直接返回内存单例，启动耗时降至 **0 毫秒**。

### 2. 密码学安全令牌 (Secure Token) 与伪随机流异或混淆 (XOR)
* **痛点**：明文或简单 Base64 格式的激活码极易被逆向者肉眼识破或伪造。
* **实施方案**：
  * 采用 `APP-SEC-<Base64Payload>.<Sig16>` 格式；
  * 载荷包含机器码、到期日代码（如 `PERM` 或 `20261231`）、客户名、工位编号；
  * 采用基于私钥哈希派生的伪随机字节流进行异或混淆（XOR），外层加上 HMAC-SHA256 防篡改签名截断；
  * 本地生成 `license.lic` 加密证书文件。

### 3. 单调递增时钟看门狗 (防倒拨时钟白嫖)
* **痛点**：用户购买限时试用/年度授权后，通过断网并将 Windows 系统时间倒拨几个月实现无限期使用。
* **实施方案**：
  * 本地持久化维护异或加密的时钟看门狗状态 `.time_guard.enc`；
  * 记录历史达到过的最大时间戳 `last_monotonic_ts`；
  * 若检测到当前系统时间早于历史最大时间超过 90 秒，立即判定为恶意调表作弊并锁定阻断。

### 4. 核心物理仿真计算底层“暗桩”
* **痛点**：攻击者在 GUI 入口处绕过激活弹窗直接拉起主界面。
* **实施方案**：
  * 在 `CoilPhysicsEngine.calculate()` 核心算法入口深层植入授权校验；
  * 内部设置 5 秒内存安全缓存防止频繁验签影响计算效率；
  * 一旦验签失败，核心解算直接阻断，彻底防御反编译绕过攻击。

### 5. Cython 编译 Windows 原生 C 机器码 (.pyd)
* **痛点**：Python 的 `.pyc` 字节码在逆向工具面前如同裸奔。
* **实施方案**：
  * 编写 `build_cython.py` 脚本；
  * 将 `src/core/physics_engine.py`、`src/core/models.py`、`src/core/license_manager.py` 编译为 Windows PE 动态库 `.pyd`（内部为 x86/x64 机器码）；
  * 构建发布包时物理删除对应的 `.py` 与 `.c` 源文件，使反编译器彻底失效。
